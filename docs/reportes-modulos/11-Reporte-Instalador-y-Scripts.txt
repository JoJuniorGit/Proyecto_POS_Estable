--------------------------------------------------------------------------------
1. DESCRIPCIÓN
--------------------------------------------------------------------------------
El instalador (Inno Setup) recoge en páginas de asistente: datos de PostgreSQL,
credenciales del admin semilla, nombre del negocio y URL de actualizaciones;
luego registra el servicio Windows (NSSM o fallback sc.exe), configura el
firewall y lanza el cliente. Configure-PosService.ps1 hace la configuración
idempotente (fusión de variables de entorno del servicio). build-release.ps1
publica los 3 binarios y compila el front. start.bat levanta todo en desarrollo.

[INS-3] Firewall: HTTP 5000 y HTTPS 5001 abiertos sin HTTPS servido (C2/R6).
  La v1 describía el firewall con solo HTTP 5000. Rev.2: Configure-

[INS-4] Contraseña del admin semilla con mínimo de 4 caracteres.
