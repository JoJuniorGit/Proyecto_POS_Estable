--------------------------------------------------------------------------------
1. RESUMEN DE EVOLUCIÓN ARQUITECTÓNICA (FASES 1 A 4)
--------------------------------------------------------------------------------
El subsistema de instalación automatiza el aprovisionamiento del POS como Servicio Windows:

1. Generación y Protección de Secretos JWT (C1 / INS-1 ✅):
   - Configure-PosService.ps1 genera claves de 512 bits mediante CSPRNG criptográfico
     ([Security.Cryptography.RandomNumberGenerator]) si no se suministra una clave válida.
   - Aplica ACLs restrictivas en el Registro de Windows (HKLM:\Software\POS), restringiendo
     la lectura exclusivamente a cuentas SYSTEM y Administradores locales.

2. Resiliencia del Servicio Windows y Fallback Nativo (UPD-2 ✅):
   - Integración nativa con UseWindowsService() en Program.cs.
   - Scripts de configuración y actualizador soportan fallback nativo a sc.exe si el
     binario nssm.exe no se encuentra en el entorno.

3. Reglas de Firewall Idempotentes:
   - Configuración automática de reglas de entrada en el Firewall de Windows para los
     puertos 5000 (HTTP) y 5001 (HTTPS), con limpieza de reglas huérfanas previas.

--------------------------------------------------------------------------------
2. MATRIZ DE ESTADO DE HALLAZGOS (REV. 7.0)
--------------------------------------------------------------------------------
- C1 / INS-1 (Generación de clave JWT): ✅ CORREGIDO (CSPRNG 512 bits + ACLs).
