   - 6 pruebas unitarias para Logistics.Module:

     * Actualización de estados de entrega (PendingPickup -> Assigned -> InTransit -> Delivered).
     * Validación de transiciones ilegales y excepciones.

3. GlobalExceptionHandlerMiddlewareTests.cs (Fase 2 ✅, Commit 1e8b29f):
   - 10 pruebas unitarias para el middleware de excepciones:
     * Mapeo de PostgreSQL SQLSTATE 23502 (NOT NULL) a HTTP 400 Bad Request.
     * Mapeo de SQLSTATE 23505 (violación de unicidad) a HTTP 409 Conflict.
     * Mapeo de SQLSTATE 23503 (clave foránea) a HTTP 400.
     * Mapeo de fallos de conexión (08006, 08001) a HTTP 503 Service Unavailable.
     * Validación de campos duales ('message' / 'Message' y 'traceId' / 'TraceId').
